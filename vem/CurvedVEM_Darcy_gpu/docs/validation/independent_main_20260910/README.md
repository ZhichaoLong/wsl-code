# 独立主函数与时间/空间尺度验收

## 文件与工作方式

- 新建 `main/`，Darcy 1/2、MS 1/2/3/4 各有独立主函数。每次只计算所选方程算例的网格列表；旧单网格/批量/性能/CLI 入口迁入 main 并保留。src 内没有主函数。
- Makefile 自动发现 main/*_main.cpp。`make 名字` 仅编译，`./build/名字` 才运行。所有参数和输出名称在主函数内可见。
- 新增 `mesh_study` 工具与结构化 `CaseResult`，不通过读取 JSON 来拼接终端结果。
- 数学 GPU 核和 GMRES 方法未修改；求解驱动增加网格复用、诊断频率、关闭最终解写盘、终端结果和计时。

## 已实际完成的运行

工作目录为工程根目录，正式默认入口验证：

```bash
make -j4
./build/Darcy_straight
```

## 主机与文件检查

`test_study_cpu.log` 检查 k=0..4 的 Euler/BDF2 指数、实际 dt 不超过目标、dt*N=T、BDF2 至少两步、2^a*5^b 步数、超过上限拒绝、真实零阶/负阶、无效阶为 NaN。模拟误差 h² 验证累计表公式，并故意让第三层网格缺失，前两层 CSV/文本结果正确保留。这不是数值解验证，GPU 数值另见上方记录。

`test_study_results.log` 独立从 CSV 复算全部实测阶，核对每组分/每层数值、共同 T、error_interval、关闭解保存、计时正值及旧解；通过。

`test_study_diagnostics.log` 核对中间步所有组分误差、质量和单步/累计耗时输出。最终编译无 warning/error。使用获准的沙箱外 GPU 驱动；没有重跑受 WDDM 限制的 Compute Sanitizer。

## 输出与清理

outputs/ 保存本轮表、参数、逐网格报告及日志快照；output/ 中保留原完整结果。history.csv 仅含配置指定的诊断步，最终步必有。convergence.csv 以网格/组分为行，同时保留两种域的误差、选定范数的阶、时间网格和墙钟耗时。
