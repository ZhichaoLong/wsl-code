# 验收与性能报告

日期：2026-09-10。硬件：RTX 5060 Laptop GPU，26 SM，约 8 GiB；CUDA 13.0，双精度，默认 128 线程/block、4096 单元/launch。

## 1. 验收结论

- 已完成独立 GPU 工程并完整重编译；最终编译无 warning/error。
- 原 CPU 网格/积分/多项式/算例快照逐字节未变，原项目未被本任务修改。
- 基础投影、方向奇偶性、全局算子、非零边界、非线性系数、时间推进和误差均经过分阶段测试。阶段测试源码按要求在通过后删除，原始日志保留于 [validation](validation)。
- 当前支持两个 Darcy 算例、四个 MS 算例，以及 k=0..4；四阶的验证方式与原 CPU 可对照的 k=0..3 区分记录。

## 5. 最终 GPU 规模与缓存更新基准

| 单元数 | 全局自由度 | CPU 网格/固定几何+上传+基础/缓存准备 s | GPU 基础重建 ms | 初值直接积分+预条件 ms | Picard 收缩+预条件 ms | matvec ms |
|---:|---:|---:|---:|---:|---:|---:|
| 4096 | 123648 | 0.107 | 13.676 | 41.434 | 0.931 | 0.148 |
| 65536 | 1969152 | 1.849 | 242.032 | 644.577 | 17.843 | 2.982 |

4096 单元取 20 次平均，65536 单元取 3 次平均。**这两个大规模运行是准备/算子基准，没有执行完整 PDE 时间推进。** k=1 四边形下，65536 单元持久基础因子约 87 MiB，方程因子+几何矩缓存约 228 MiB；这些数字不含积分数据及 Krylov 向量。

线程数 32/64/128 的 matvec 约 0.127–0.130 ms，256 线程约 0.187 ms（4096 单元，早一轮直接积分配置）。寄存器、local/shared memory 的真实查询结果见 [最终资源日志](validation/final_bench65536/run.log)。

## PETSc GPU 代数层重构验收

本页前面的矩阵准备/自写 Krylov 计时是历史实现的数据。当前持久代数对象为 PETSc Mat/Vec，求解为 FGMRES + cuSPARSE ILU(0)，Darcy natural、MS ND。最终六例、Euler/BDF2、MatShell、k=4 求解、32 组算子/置换与重复释放检查通过。

MS4 k=1 实际 32/64/128 首步迭代耗时约 3.614/20.339/135.569 s，相对旧版首步约 2.51/2.29/1.95 倍；不是完整 T=0.1 的性能结论。24 轮预热后重复释放的主机跟踪分配与空闲显存均保持恒定，未观察到泄漏。范围、异常路径、工具限制和原始日志见 [本轮完整验收](validation/petsc_refactor_20260910/README.md)。
