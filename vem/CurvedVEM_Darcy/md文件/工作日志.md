### 关键设计决策（补充）

4. **扩散矩阵 A 的值不在域间变换**：A(c) 只依赖浓度点值，物理域/计算域对应点值相同。几何变换体现在加权张量中：`W_ij = A_ij · JᵀJ / detJ`。

### 新增工作

#### 10. 一致性刚度矩阵 K_ac

**实现函数**：`getMatrixK_ac(G_weighted, L2Proj_ploy)`
- 公式：`K_ac = Π_poly^T · G_weighted · Π_poly`
- 三次矩阵乘法：先 `G * Π`，再 `Π^T * (G*Π)`
- 维数：通量自由度 × 通量自由度（k=1 时为 11×11）
- 结果验证：对称 ✅，维数正确 ✅

#### 11. A_ij 稳定化系数 α_E 和 K_as

**稳定化系数**：
- `computeStabilizationCoeffInit(mesh_idx, i, j)` — 初值模式
- `computeStabilizationCoeffPoly(mesh_idx, i, j, u_coeff)` — 数值解模式
- α_E = ‖单元平均加权张量 W_ij‖_F（Frobenius 范数）
- 验证：A(0,1)=0 时 α=0 ✅，量级合理 ✅

**稳定化矩阵**：
- `HdivMatrixK_as(stab_coeff, L2Proj_basis)`
- 公式：`K_as = α_E · (I - Π_dof)^T (I - Π_dof)`
- 两种模式：`getMatrixK_as_init()` / `getMatrixK_as_poly()`

#### 12. c* 线性项的稳定化系数和 K_as

**新增公共接口**：
- `getStabilizationCoeffCstar(mesh_idx)`
- `getMatrixK_as_cstar(mesh_idx, L2Proj_basis)`
- 与 A_ij 模式同样的 Frobenius 范数逻辑，加权张量为 `W_c* = c* · J^T J / detJ`
- 验证：c*=0.1 时 α ≈ 0.193，量级正确 ✅

**与直边 MS_FVM 的差异**：
- 直边版本 A 是标量，稳定化系数直接取 A 的单元平均值
- 曲边版本是张量的 Frobenius 范数单元平均，差 √2 倍
- 用户确认：相差 √2 无所谓，实现方式正确

#### 13. 右端项 getLocalRhs（初值模式完成）

**核心实现**：`vemHdiv_source_mk(mesh_idx, comp_idx, ploy_mk, is_initial_first_tstep)`

**被积函数**：`(f_i + (1/Δt)·c_i^{prev}) · m_r`

两部分都乘以测试基函数 m_r：
1. **源项 f_i**：`computational_source_f(comp_idx, xi, eta)`（已乘 detJ）
2. **历史项 (1/Δt)·c_prev**：
   - 初值模式：解析初值函数 × detJ / Δt
   - 数值解模式：单项式系数还原浓度 × detJ / Δt

**HdivVecRhs 结构**：
- 通量块：全 0（H(div) 方程无体积右端）
- 浓度块：每组分单独积分填充
- 布局：`[通量_组分0, ..., 通量_组分n | 浓度_组分0, ..., 浓度_组分n]`

**验证结果**（单元 0, k=1, 3 组分）：
- 通量块 33 个分量全部为 0 ✅
- 浓度块 9 个分量非零，量级合理 ✅
- L2 范数 ≈ 18.74

#### 14. getLocalToGlobalDofs 和 getElementConcCoeffs

**getLocalToGlobalDofs(elem)**：
- 布局：`[组分0通量, 组分1通量, ... | 组分0浓度, 组分1浓度, ...]`
- 每个组分内部编号与 Darcy（单组分）一致
- 组分偏移：`comp_idx × 单组分通量/浓度总自由度`
- 无拉格朗日乘子（MS 方程不需要）

**getElementConcCoeffs(elem, comp_id, use_prev_time)**：
- 从全局解向量提取指定单元指定组分的浓度单项式系数
- `use_prev_time=true` → `solution_prev_time_`（右端项历史用）
- `use_prev_time=false` → `solution_`（当前 Picard 迭代用）

#### 15. 方向调整 computeAndApplyDirectionAdjustment

**实现逻辑**（参照 DarcySolver + 直边 MSSolver）：
1. 先算**单组分**通量自由度的方向符号
   - 边自由度：偶次多项式根据边方向判定，奇次不变
   - 内部通量自由度：恒为 +1
2. 复制到**所有组分**（所有组分共用同一套几何边方向）
3. 浓度自由度：恒为 +1（标量，不需要方向调整）
4. 应用到矩阵：`K[i][j] *= dir[i] * dir[j]`

**关键概念**：
- 全局边只有一个参考法向方向
- 两个相邻单元的方向调整向量在共享边上符号**不同**（一个+1一个-1）
- 调整后两个单元在共享边上的矩阵元统一到全局方向

### 关键设计决策

1. **非线性系数分解**：`element_diffusion_coeff` 和 `polynomial_diffusion_coeff` 均返回纯非线性部分 A(u)（不含 c*），稳定项 c* 在 Hdiv 矩阵组装时单独加到对角线。与 MS_FVM 的 `mid_A_coeff` / `poly_A_coeff` 行为完全一致。

2. **多项式系数存储布局**：所有组分的单项式系数平铺在一个向量中，布局为 `[comp0_monom0, comp0_monom1, ..., comp1_monom0, ...]`，与 MS_FVM 保持一致。

3. **单项式基函数缩放**：使用缩放坐标 `xm = (x - xD)/hD, ym = (y - yD)/hD`，与 `BasisFunctionPloy::evalMonomial2D` 一致。
