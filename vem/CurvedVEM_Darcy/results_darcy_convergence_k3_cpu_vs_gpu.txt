  分析：
    - 小规模（< 8x8）：CPU 更快（GPU 数据传输开销占主导）
    - 中等规模（16x16）：GPU 优势开始显现（3.3x 加速）
    - 大规模（32x32）：GPU 迭代数激增（BJACOBI 预条件效果差），加速比下降到 1.3x
    - CPU ILU 预条件效果好（迭代数少），但单步迭代慢
    - GPU BJACOBI 预条件效果差（迭代数多），但单步迭代快
    - 交叉点大约在 16x16 附近，超过后需要更好的 GPU 预条件才能充分发挥 GPU 性能

====================================================================================================
  总结
====================================================================================================

  1. 数值结果：CPU 和 GPU 完全一致，误差差异在舍入误差范围内
  2. 收敛阶：两者均达到理论 k+1 = 4 阶，压力 ~4.0 阶，通量 ~4.0 阶
  3. 求解速度：
     - 小规模问题 CPU 更快（GPU 数据传输开销）
     - 中等规模（~2万自由度）GPU 有 3.3x 加速
     - 大规模（~13万自由度）因 BJACOBI 预条件迭代数激增，加速比降至 1.3x
  4. 建议：
     - 若追求最佳 GPU 性能，应使用更好的预条件（如 Schur 补 + GAMG）
     - 矩阵组装是当前最大瓶颈，可考虑将组装也移到 GPU
